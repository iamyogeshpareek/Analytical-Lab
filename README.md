Analytical Lab — Analytical Procedure Workbench is a standalone, browser-based educational tool for organizing calculations used in analytical procedure validation. It is intended to support research scholars and analysts who want to enter their measurements in Excel, review calculations, and generate a report without installing a desktop application.

The tool accepts Excel workbooks and calibration CSV files. It can calculate calibration models, regression equations, coefficients of determination, back-calculated concentrations, and estimated limits of detection and quantitation from calibration data. When the workbook contains compatible tables, it can also summarize recovery, intra-day precision, inter-day precision, and robustness. For simultaneous methods with more than one analyte, calibration curves are reported separately, and users can map accuracy and precision data to the corresponding calibration.

The report presents the selected equations, plots, calculated values, and optional acceptance-criteria assessments. Criteria are entered by the user according to the intended use and approved protocol; the tool does not assume universal limits. The in-app Help section explains accepted column labels and how to arrange raw measurements so the workbook can be interpreted. Users should check detected tables and mappings before relying on results.

Calculations run locally in the browser. The app does not upload workbook contents to a server, and example or private laboratory data are not included in this repository. Users should provide numeric raw readings and retain their original records for independent review.

Analytical Lab is informed by analytical procedure validation concepts described in ICH Q2(R2). It is training and educational software, not a validated or regulated system. It does not establish ICH compliance, replace an approved validation protocol, assess every validation characteristic, or make a scientific decision about method suitability. Results, assumptions, units, formulas, data mappings, and conclusions must be independently checked against applicable guidance and laboratory procedures.

This project is being developed for research scholars by a research scholar and will continue to improve through feedback, calculation checks, and additional examples. Suggestions, issue reports, and contributions are welcome. Before using the tool for research decisions, users should understand its calculation methods and limitations and verify outputs with an independent reference calculation and documented examples.
